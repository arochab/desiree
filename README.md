# Désirée

Public portfolio demonstration by Adam Chabbi. The personal AI workspace and all private source data remain separate.

This static demo uses fictional messages, calendar events, memories and Ableton metadata. Responses are scripted. Actions and memories persist only in the visitor's browser and can be reset. No model, mailbox or personal backend is connected. The MIDI download is a real example file containing the displayed pattern.

The private implementation combines Python, SQLite, bounded tools, source captures, persistent actions and human approval. Its voice features use Windows speech services. OpenJarvis DigestStore is integrated under Apache 2.0; the complete OpenJarvis system and permanent wake word are not running. Continuous source synchronization and Ableton Live control remain unfinished.

Public pages: English/French overview, French interactive demo, French chaptered video guide. Libraries bundled locally: GSAP and Three.js. Brand assets are used only to identify the corresponding sources; no endorsement is implied.

Serve this directory with any static HTTP server. No build or installation needed. See the attribution file for retained notices.
